El problema que resuelve Flexbox

Antes de la introducción de Flexbox, las propiedades disponibles para construir layouts en CSS eran principalmente float y position. Ambas herramientas fueron diseñadas originalmente con otros propósitos y presentaban limitaciones importantes al momento de resolver problemas de distribución que hoy se consideran elementales, entre ellos los siguientes.

  1. Centrar verticalmente un bloque de contenido dentro de su elemento padre.
  2. Hacer que varios elementos secundarios de un contenedor ocupen una cantidad igual de espacio, sin importar el ancho o el alto disponible.
  3. Hacer que columnas dispuestas una junto a otra adopten la misma altura, incluso cuando contienen cantidades distintas de contenido.

Flexbox, abreviatura de Flexible Box Layout, fue creado específicamente para resolver este tipo de problemas mediante un modelo de distribución pensado para adaptarse al espacio disponible.

El modelo de caja flexible

Flexbox es un modelo de diseño unidimensional: distribuye elementos a lo largo de una sola dirección a la vez, ya sea horizontal o vertical. Se compone de dos partes que se definen una respecto de la otra.

  • Contenedor flexible (flex container): el elemento padre en el que se establece display: flex. Otorga a sus hijos directos las propiedades de un elemento flexible.
  • Elementos flexibles (flex items): los hijos directos del contenedor flexible. Su comportamiento depende de las propiedades definidas tanto en el contenedor como en el elemento mismo.

Los ejes de distribución

Dentro de un contenedor flexible, los elementos se distribuyen con respecto a dos ejes perpendiculares entre sí.

El eje principal (main axis) es el eje que sigue la dirección en la que se colocan los elementos flexibles; su dirección depende del valor de flex-direction. El inicio y el final de este eje se denominan inicio principal (main start) y final principal (main end). El eje transversal (cross axis) es perpendicular al eje principal; su inicio y su final se denominan inicio transversal (cross start) y extremo cruzado (cross end).

Esta distinción es la base para comprender el efecto de las propiedades que se presentan a continuación: unas actúan sobre el eje principal y otras sobre el eje transversal.

Propiedades del contenedor flexible

Las propiedades que se describen en esta sección se aplican al elemento que tiene establecido display: flex, y afectan la forma en la que se distribuyen todos sus elementos flexibles hijos.

Dirección y ajuste de línea

La propiedad flex-direction define la dirección del eje principal, con los valores row, row-reverse, column y column-reverse. Por defecto, todos los elementos flexibles intentan ajustarse en una sola línea; la propiedad flex-wrap, con los valores nowrap, wrap y wrap-reverse, permite que se distribuyan en varias líneas cuando no hay suficiente espacio. Ambas propiedades pueden combinarse mediante la abreviatura flex-flow.

Distribución en el eje principal

La propiedad justify-content distribuye el espacio libre sobrante a lo largo del eje principal, cuando los elementos no ocupan la totalidad del contenedor. Admite los valores flex-start, flex-end, center, space-between, space-around y space-evenly.

Propiedades de los elementos flexibles

A diferencia de las propiedades anteriores, las que se describen en esta sección se aplican directamente sobre cada elemento flexible, y permiten modificar su comportamiento de manera individual.

Capacidad de crecimiento y reducción

La propiedad flex-grow define si un elemento puede crecer para ocupar el espacio sobrante del contenedor. Acepta un número sin unidad que actúa como proporción: si todos los elementos tienen el mismo valor, el espacio se reparte de manera equitativa; si uno de ellos tiene un valor mayor, ocupará una porción proporcionalmente mayor. De manera análoga, flex-shrink define la capacidad de un elemento para reducirse cuando no hay espacio suficiente, y flex-basis establece su tamaño inicial antes de repartir el espacio restante. Estas tres propiedades pueden combinarse mediante la abreviatura flex, con la sintaxis flex: grow shrink basis;.

Dicho tamaño base se establece mediante flex-basis, que puede expresarse en unidades absolutas o en porcentaje.

La propiedad order modifica el orden visual en el que se presentan los elementos, con independencia del orden en el que aparecen en el documento HTML.
