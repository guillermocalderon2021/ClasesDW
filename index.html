Unidad II. Maquetación de sitios web y diseño web responsivo

Desarrollo Web I — Ciclo III 2026

Contenido de la unidad

Esta unidad aborda los mecanismos que utiliza el navegador para distribuir el contenido de una página y las estrategias para que dicha distribución se adapte a distintos tamaños de pantalla. Se cubren, en orden, los siguientes temas: Flexbox, posicionamiento y visualización, CSS Grid, diseño web responsivo, media queries y contenido responsivo, y el uso del framework Bootstrap, tanto en su sistema de malla como en sus componentes.

Cada tema incluye ejemplos de código HTML y CSS que pueden modificarse directamente en esta misma página. El panel de la derecha de cada ejemplo muestra el resultado de dicho código de manera inmediata, lo que permite observar el efecto de cada propiedad sin necesidad de herramientas externas.
